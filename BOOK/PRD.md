# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## Project Overview

Name: THE Vibe LAB (or SendTheSong clone)

Purpose: An interactive platform where users can send anonymous messages attached to specific iTunes tracks, mix songs based on Zodiac and Mood, and share the results to social media stories.

## Core Features

1. Hero Section &amp; Creation Form: User inputs recipient name, message, and selects a song via the iTunes Search API.

2. The Vibe Mixer: User selects Zodiac and Mood to generate an aesthetic output.

3. Share to Story: Generates a downloadable/shareable image of the message and track (using html-to-image).

4. Infinite Marquee: A continuously scrolling section displaying recently sent public messages.

5. Browse &amp; Search: A dedicated view to search for messages by recipient name.

6. Detail View: A modal displaying the full message and the track's 30-second audio preview.
